# Pack to Pitch

Pack to Pitch is a football management and tactics simulation game built in Python using Tkinter, inspired by games such as Football Manager and FIFA Ultimate Team.

Players can create and manage a football team, build a squad through player packs, customise formations and tactics, and compete through a 10-division progression system using a custom match simulation engine.

## Features

- Graphical user interface built with Tkinter
- Create, load and delete career saves across four save slots
- Squad management with starting XI and substitute players
- Seven available formations
- Player roles and a chemistry system
- Customisable team tactics
- Player pack system with different pack types and rarities
- In-game coin economy and player quickselling
- Player database with individual ratings and attributes
- 10-division progression system with promotion, relegation and title targets
- Division-based opponent generation
- Custom football match simulation engine
- Live match commentary, score, shots and expected goals (xG)
- Post-match player ratings and rewards
- Adjustable match simulation speed
